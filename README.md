# ICS-214

This repository contains the published static files for the ICS-214 progressive web application (PWA). The application is written in Angular with TypeScript.

Application:
https://kd2grs.github.io/ics214/

## What it Does

Create and maintain ICS-214 Activity Logs on your phone, tablet or computer. Even without an Internet connection.

## Disclaimer

The application is an independent tool for creating ICS-214 Activity Log forms. It is not affiliated with, associated with, authorized by, endorsed by, or otherwise officially connected to FEMA, the U.S. Department of Homeland Security, or any other government agency.
